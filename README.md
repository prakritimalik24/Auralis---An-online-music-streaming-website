# 🎵 Auralis

## 🔗 Live Demo
https://auralis-sable.vercel.app/

## 📖 Description

Auralis is a full-stack music streaming web application where users can discover, search, play, favorite, and organize music through playlists. Artists can upload their own music and create albums, making Auralis a platform for both music listeners and creators.

## ✨ Features

### 👤 User Features
- User registration and login
- Browse and search music
- Play local and Jamendo music
- Favorites
- Recently Played
- Create and manage playlists
- Search for songs, albums, and artists
- Persistent music player
- Logout and switch profile

### 🎤 Artist Features
- Artist registration and login
- Upload music
- Create albums
- Manage uploaded music
- View uploaded albums and songs

### 🛠️ Tech Stack

**Frontend:** React, Tailwind CSS, React Router, Axios, Vite

**Backend:** Node.js, Express.js, MongoDB, Mongoose, JWT, Multer

**APIs & Services:** Jamendo API, ImageKit

**Deployment:** Vercel, Render
